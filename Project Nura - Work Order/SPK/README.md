# Project Nura — Work Order / SPK Upper

Aplikasi web lokal berada di **[webapp](webapp/README.md)**.

- Windows: unduh repositori sebagai ZIP, ekstrak, buka `webapp`, lalu jalankan `start.bat`.
- macOS/Linux: buka `webapp` dan jalankan `sh start.sh`.
- Python 3.11+ diperlukan. Database SQLite dibuat otomatis pada komputer yang menjalankan aplikasi.

[Petunjuk lengkap, alur penggunaan dan backup](webapp/README.md)

Dokumen Excel dan PDF versi draft terdahulu berada pada folder [output](output/). Dokumen tersebut merupakan hasil analisis/penataan, bukan SPK yang telah disahkan untuk produksi.
